# Backend

FastAPI API server with async SQLAlchemy 2, Alembic and PostgreSQL. Layers: Router → Service → Repository. Session auth (email + password, Google OAuth) and an example `items` feature are included.

## Run

With Docker, from the project root: `docker compose up -d` (the container applies the migrations on start).

Without Docker (hot reload):

```bash
docker compose up -d db          # from the project root: Postgres only
cp .env.example .env             # DB_URL must match POSTGRES_* in the root .env
uv sync
uv run alembic upgrade head
make run                         # http://localhost:9095, docs at /docs
```

## Common commands

| Command | What it does |
|---|---|
| `make run` | `uvicorn --factory app.main:create_app --reload --port 9095` |
| `make test` / `make test-cov` | End-to-end suite (needs Docker), with coverage for `test-cov` |
| `make lint-all` / `make check` | Ruff fix + format / check only |
| `make migrate-new msg="..."` / `make migrate` | New autogenerated migration / apply migrations |
| `make help` | All targets |

## Tests

All tests are end to end: `uv run pytest` starts Postgres in Docker, runs the migrations, starts the real server and sends HTTP requests. There are no unit tests and no mocks. Tests live in `tests/e2e/`; start with the docstring of `tests/e2e/conftest.py`.
